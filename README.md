# Voi-Maze

**Voi-Maze** is an immersive, high-speed, blockchain-educational maze game built specifically for the **Voi Network** ecosystem. 

## 🌌 What is it?
In Voi-Maze, players are dropped into a visually stunning, cyberpunk-themed "Data Network" maze. The goal is to navigate the network, intercept data packets (Trivia Nodes), and answer questions about the Voi blockchain to unlock the path forward. 

The faster a player reaches the exit portal while accurately answering questions, the higher they rank on the Global Leaderboard. It's a test of both reflexes and Voi knowledge!

## 🚀 Why was it built?
I built Voi-Maze to gamify the learning experience surrounding the **Voi Network**. Learning about blockchains, nodes, and ecosystem mechanics can often feel like reading dry documentation. 

Voi-Maze changes that by turning education into an arcade speedrun. It is designed to:
- **Onboard newcomers** to the Voi ecosystem in a highly engaging, low-friction way.
- **Reward community members** for their knowledge of the blockchain.
- **Create a competitive social experience** through the global real-time leaderboard.

## 🛠️ Features
- **Immersive Cyberpunk Aesthetic:** Built with modern Glassmorphism UI, dynamic neon lighting, and holographic overlays.
- **Global Leaderboard:** Powered by Firebase Realtime Database to track the fastest speedrunners across the world.
- **Responsive Design:** Fully playable on both Desktop and Mobile devices with an intuitive on-screen D-Pad.
- **Power-ups & Mechanics:** Utilize Time Freezes, Hints, Speed Boosts, and Map Reveals to optimize your run.
